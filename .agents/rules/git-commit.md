# Git Commit Guidelines

- **Always commit changes**: Whenever code, styling, or documentation changes are made and verified, always create a git commit automatically before completing the turn.
- **Descriptive messages**: Write concise, conventional commit messages (e.g., `feat: ...`, `style: ...`, `refactor: ...`, `fix: ...`).
- **Build verification**: Verify that `npm.cmd run build` passes before committing.
